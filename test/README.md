# テスト

拡張APIをスタブしたブラウザ上のテストページです。ビルドやテストランナーは不要で、
`extension/` の実ファイルをそのまま読み込んで検証します。

## 実行方法

`file://` で直接開くとスクリプトの読み込みがブロックされるため、
リポジトリのルートを簡易サーバーで配信して開きます。

```bash
python -m http.server 8731
```

ブラウザで `http://localhost:8731/test/index.html` を開くと結果が一覧表示されます。
最終行が `ALL PASS` であれば成功です。

## 検証している内容

- 注文日時の表記ゆれ(`2024年5月3日` / `2024/05/03` / `2024-05-03`)の解析と降順ソート
- 一覧ページの行抽出・最大ページ数の取得・注文IDによる重複除去(二重カウント防止)
- 注文詳細ページからの「お支払金額」とステータスの抽出
- 取得したHTMLにscriptタグや画像が含まれていても、解析結果の文書は不活性で
  スクリプトが実行されないこと
- 年別・月別の集計値と、年行クリックによる開閉
- キャンセル除外・金額取得失敗の表示、注文番号のHTMLエスケープ

BOOTHへ実際にアクセスする処理(ログイン状態でのfetch、ページング)は対象外です。
